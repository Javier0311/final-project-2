**Monkey Food** is a responsive static website designed for a jungle-themed burger restaurant. This project serves as the final submission for the Web Development Course, demonstrating mastery of semantic HTML5, modern CSS3 (Flexbox, Grid, Animations), and vanilla JavaScript.

## 📖 Project Description

The main goal was to create an immersive user experience ("Dive into the Jungle") using a **Dark Mode** design with vibrant accent colors. The site is fully responsive, adapting fluidly from mobile devices to large desktop screens.

### ✨ Key Features

* **Responsive Design:** *Mobile First* strategy with breakpoints at 600px, 850px, and 1200px.
* **Interactive Navigation:** Custom hamburger menu with CSS animations and state control via `input:checked` (no heavy JS dependency).
* **Advanced CSS:**
    * **CSS Variables** (`--color-monkeys`) for thematic consistency.
    * **Keyframe Animations** (`@keyframes balance`) for dynamic elements.
    * **Flexbox & CSS Grid** for complex layouts.
* **JavaScript Slider:** "What they say in the jungle" testimonial carousel with auto-scroll and pause-on-hover functionality.
* **Styled Forms:** "Work with Us" page with custom file selectors.
* **Custom 404 Page:** Unique design that guides the user back home.
* **Accessibility:** Use of semantic HTML and WCAG contrast validation.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure (`<header>`, `<main>`, `<section>`, `<footer>`, `<details>`).
* **CSS3:** Custom stylesheet without heavy frameworks (Bootstrap, Tailwind).
* **JavaScript (ES6):** Logic for the comments slider.
* **FontAwesome:** Iconography for social media and UI elements.
* **Google Fonts:** *Anton*, *Bebas Neue*, and *Roboto* typefaces.
